# Recipes

Each recipe describes a kind of launcher: who it's for and what makes it good. Point your agent at one and adjust it to
taste, for example: *"Build the seniors recipe, with bigger text and my daughter's favorite apps."*

Recipes are design goals, so `tools/check.sh` rejects commands, links, code blocks other than JSON, and permissions the
recipe doesn't declare. Every new or changed recipe also needs review by a maintainer.
